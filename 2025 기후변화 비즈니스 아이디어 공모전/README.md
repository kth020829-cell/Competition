## 📌 프로젝트 개요

**Aider**는 폭염·한파·미세먼지 등 극단적 기후 환경에서 **노인, 만성질환자, 1인가구 등 기후 취약계층**을 보호하기 위한 **AI 기반 기후적응형 돌봄 플랫폼**입니다.

기존의 기후변화 대응이 온실가스 감축 등 **'대응(mitigation)' 중심**이었다면, Aider는 변화된 환경 속에서 스스로를 보호하기 위한 **'적응(adaptation)' 중심** 전략에 초점을 맞춥니다.

웨어러블 생체신호, IoT 환경센서, 공공 기후데이터를 융합하여 자체 개발한 **CHAI(Climate Health Adaptation Index)** 알고리즘으로 개인별 기후건강 위험지수를 실시간 산출하고, 돌봄 자원을 선제적으로 배분합니다.

---

## 🎯 해결하고자 하는 문제

- 폭염·한파로 인한 온열·한랭질환자 매년 증가
- 기후 취약계층(고령자, 만성질환자)의 건강 악화 및 돌봄 공백
- 현재 돌봄 체계는 **'재난 발생 후 대응' 중심** → 사전 예측·선제 관리 부재
- 돌봄 인력의 우선순위 없는 비효율적 대응
- '기후'와 '건강'을 통합 분석하는 플랫폼의 부재

## 💡 핵심 아이디어: CHAI 모델

CHAI는 기후로 인한 건강 위험이 단일 요인이 아닌, **'기후 변화 ↔ 신체 반응 ↔ 생활환경 ↔ 개인 취약성'** 네 가지 요소가 상호작용한 결과라는 관점에서 설계되었습니다.

### CHAI 수식

```
CHAIₜ = σ( f(Cₜ, Bₜ, Eₜ) + w_personal )
```

| 변수 | 의미 | 설명 |
|------|------|------|
| **Cₜ** (Climate) | 기후 스트레스 | 기온·습도·예보·급변 신호를 함수화한 외부 기후 부담 |
| **Bₜ** (Bio-behavioral) | 생체 반응 | HR, HRV, 체온 등 신체의 단기 반응 패턴 |
| **Eₜ** (Environmental) | 환경 노출 | 실내 온·습도, CO₂, WBGT 등 누적 부담 |
| **w_personal** | 개인 취약성 보정값 | 나이, 기저질환, BMI 등 개인 고유 민감도 |

### Personalization Layer

```
w_personal = α · V_personal + β · Sₜ + γ · Rₜ
```

- **V_personal**: 장기 취약성 임베딩 (기저질환, 연령 등)
- **Sₜ**: 실시간 생체 변화 (HR, HRV, SpO₂ 등)
- **Rₜ**: 현재 환경 강도 (WBGT, PM 농도 등)
- **초기 가중치**: α=0.5, β=0.3, γ=0.2 (선행 연구 기반)
- 추후 사용자 데이터 축적 시 메타러닝/gradient 기반으로 자동 조정

### 출력

- 0~1 사이 위험 점수 (Sigmoid)
- 3단계 분류: **Safe / Warning / Critical**

## 🧩 주요 기능

### 1. 시민(취약계층) 앱
- 실시간 CHAI 위험도 대시보드
- 기후 맞춤 행동 권고 (예: "이틀 뒤 폭염, 외출 자제")
- 가족 CHAI 위험도 실시간 확인
- 긴급 도움 요청 기능
- 위험도 계산 근거 투명 제공

### 2. 돌봄요원 앱
- AI 기반 방문 우선순위 자동 배정
- 위험도 급상승 긴급 알림
- 최적 이동 경로 안내
- 방문 후 체크리스트 및 메모 기록 → AI 재학습 반영

### 3. 관리자(지자체·복지기관) 대시보드
- 행정동 단위 CHAI 위험 히트맵
- 고위험군 분포 및 변화 트렌드
- 돌봄 인력·예산·자원 효율 배분 의사결정 지원
- 성과 모니터링 및 평가(M&E)

### 4. 커뮤니티 참여자
- 위험 가구 히트맵 기반 자원봉사 매칭
- 비식별 정보로 개인정보 보호
- 지역 커뮤니티 기반 돌봄 네트워크 강화

## 🛠 기술 스택 (예정)

- **Backend**: Python (FastAPI)
- **AI/ML**: 
  - LightGBM (최종 위험도 예측)
  - TCN + Transformer (생체 시계열 분석)
  - Multi-modal DL (CNN + LSTM, 기상 영상 + 시계열)
  - EMA (환경 누적 부담 계산)
- **Frontend**: React (대시보드), React Native (모바일 앱)
- **Data Pipeline**: 공공 API 연동 + Edge AI 1차 필터링
- **Security**: AES-256 암호화, 비식별화, 연합학습 고려
