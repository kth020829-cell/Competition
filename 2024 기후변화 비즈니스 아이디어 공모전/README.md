# 🌿 Roof Station
**정부 주도의 스마트 수거함과 중고거래 플랫폼**

> 2024 국민대학교 기후변화대응 비즈니스 아이디어 공모전 출품작  
> Team **2NE1** (To New Environment) | 국민대학교 AI 빅데이터융합경영학과

---

## 📌 프로젝트 개요

기후변화로 인한 자원 고갈과 폐기물 증가 문제에 대응하여, **스마트 수거함**과 **중고거래 플랫폼**을 결합한 녹색 순환 비즈니스 모델을 제안합니다.

중고거래에 대한 관심이 높아진 10~20대를 주 타겟으로, 다회용품 반납 → 포인트 적립 → 중고거래로 이어지는 **지속 가능한 소비 생태계**를 구축하는 것이 목표입니다.

## 🌍 배경 및 문제 정의

### 왜 지금 이 서비스인가?

- 코로나 이후 **일회용품 사용 급증** → 플라스틱 쓰레기 및 환경오염 심화
- 소비자들의 **친환경 소비 인식은 높아졌지만**, 실천 수단은 여전히 부족
- 중고거래 앱 사용자 수는 2020년 이후 꾸준히 증가 (2024년 기준 약 3,378만 명 설치)
- 중고거래 이용자의 **70% 이상**이 환경 보호·자원 재활용을 중고거래의 중요한 이유로 꼽음

### 핵심 키워드

`#가치소비` `#환경보호` `#고물가` `#녹색순환`

## 🚀 서비스 소개

### Roof Station이란?

스마트 수거함 + 중고거래 앱을 결합한 **일체형 녹색 순환 플랫폼**입니다.

```
다회용품 반납 → 스마트 수거함 자동 분류 → 앱 포인트 적립 → 중고거래 활용
```

### 📦 스마트 수거함

| 기능 | 설명 |
|------|------|
| **실시간 모니터링** | IoT 센서로 수거함 상태·용량 실시간 관리 |
| **카테고리 자동 분류** | 사진 촬영 시 AI 모델이 물품 카테고리 자동 분류 |
| **이상행동 감지 CCTV** | 도난·파손 등 이상행동 실시간 감지 및 경고 |

### 📱 어플리케이션 (Roof Station App)

| 탭 | 기능 |
|----|------|
| **홈** | 환경게이지(탄소절감량 시각화), 중고물품 검색·거래 |
| **지구인** | 자원봉사·환경 캠페인 커뮤니티, 포인트 획득 |
| **지구본** | 근처 스마트 수거함 위치 지도 |
| **채팅** | 중고거래 사용자 간 1:1 대화 |
| **더보기** | 포인트 적립 내역, 개인정보 설정 |

### 💰 포인트 제도

- 다회용품 반납 시 포인트 자동 적립
- 환경 캠페인 참여 시 추가 포인트
- 적립 포인트 → 중고거래 할인·혜택으로 활용 (Lock-in 효과)

## 📊 데이터 활용 전략

스마트 수거함 **최적 위치 선정**을 위해 4가지 공공데이터를 분석했습니다.

### 1. 서울시 지하철 승하차 인원 정보
> 출처: 서울열린데이터광장

- 역별 승하차 인원 합산 → 총 승객수 기준 **상위 5개 역** 추출
- 결과: 잠실(송파구청), 홍대입구, 강남, 서울역, 구로디지털단지

```python
df_member = df.groupby(['노선명', '역명']).agg({'승차총승객수': 'sum', '하차총승객수': 'sum'}).reset_index()
df_member['총승객수'] = df_member['승차총승객수'] + df_member['하차총승객수']
df_member.sort_values(by='총승객수', ascending=False).head(5)
```

### 2. 서울교통공사 환승역 환승인원 정보
> 출처: 공공데이터포털

- 환승 인원이 많은 역 → 역사 **내부**에 수거함 우선 설치
- 평일/주말 환승 패턴을 분리하여 실내/외 설치 여부 판단

### 3. 행정안전부 지역별 주민등록 인구수
> 출처: 공공데이터포털

- 주 타겟층인 **20대 인구** 행정동별 분석
- 상위 5개 지역: 상도제1동, 화양동, 청룡동, 신촌동, 공릉2동

```python
data_c = data1.columns.map(lambda x: any(item in x for item in c))
```

### 4. 서울특별시 관악구 카페 및 커피숍 데이터
> 출처: 공공데이터포털

- 20대 인구 밀집 지역 내 **카페 위치** 분석 (Geocoding Tool 활용)
- 관악구 일대 약 **738개** 카페 확인 → 다회용품 사용 촉진 가능성 높음
- 카페 밀집도도 수거함 위치 선정 기준으로 반영

## 🤖 AI 모델 적용

### 카테고리 자동 분류 (네이버 쇼핑 방식 적용)

물품 등록 시 사진과 텍스트를 분석해 카테고리를 자동 분류합니다.

```
1. Find Product's Feature  → 색상, 브랜드, 크기, 상태 등 feature 추출
2. Morphology Analysis     → 상품명 형태소 분석 및 term 추출
3. Word Embedding          → feature를 vector로 변환 (Word2Vec)
4. CNN-LSTM Model          → 상품명 텍스트 분류
5. MobileNetV2             → 상품 이미지 분류
6. Multi Input Model       → 텍스트 + 이미지 + 부가정보 통합 학습
```

### 이상행동 감지 CCTV (AI Hub 데이터 활용)

수거함 주변 무인 환경에서의 도난·파손 리스크 관리

- 실루엣 기반 이상행동 인식 모델
- 이동궤적 기반 모델
- 스파스 코딩 방식 이상행동 인식 모델
- 프레임 예측 기반 모델
